         EMAIL SETUP — OTP codes (read this if SMTP fails on phone)
================================================================================

WHY EMAIL FAILED ON YOUR PHONE
--------------------------------
Many phones/networks BLOCK Gmail SMTP ports (465 and 587). That causes:
  "Could not convert socket to TLS" / "Could not connect to SMTP host"

The app no longer relies on sending mail directly from the phone.
It queues mail in Firestore; Firebase sends it using your Gmail on the server.

================================================================================
OPTION A (RECOMMENDED): Firebase "Trigger Email" extension
================================================================================

ONE-TIME SETUP (about 10 minutes):

1. Open Firebase Console for your project:
   https://console.firebase.google.com/project/lost-and-found-app-4cf9d

2. Go to: Build → Extensions → Browse extensions

3. Search: "Trigger Email" (by Firebase)
   Install it.

4. When asked for SMTP settings, use YOUR Gmail:
   - SMTP host: smtp.gmail.com
   - Port: 587 (or 465)
   - Username: dagmawitadeferes@gmail.com
   - Password: your 16-character Gmail App Password (no spaces)
   - From address: dagmawitadeferes@gmail.com

5. Collection name: mail   (default — keep as "mail")

6. Wait until extension status = "Installed" / "Active"

7. Rebuild and run the app. Tap Claim again.

HOW IT WORKS
------------
- App writes a document to Firestore collection: mail
- Extension reads it and sends email via Gmail (server-side — works!)
- Check your inbox for the OTP

VERIFY IN FIREBASE
------------------
- Firestore → mail collection → new documents appear when you claim
- Extension logs (Extensions → Trigger Email → Logs) show send success/failure

================================================================================
OPTION B (OPTIONAL): EmailJS over HTTPS
================================================================================

If you cannot use the extension, use EmailJS (free tier):

1. Sign up: https://www.emailjs.com
2. Add Email Service (Gmail)
3. Create template with variables: {{to_email}}, {{otp_code}}, {{user_name}}
4. Copy Service ID, Template ID, Public Key

5. Add to LostAndFoundApp/local.properties:

   EMAILJS_SERVICE_ID=service_xxxxx
   EMAILJS_TEMPLATE_ID=template_xxxxx
   EMAILJS_PUBLIC_KEY=your_public_key

6. Sync Gradle, rebuild, run.

EmailJS is tried BEFORE Firestore if these keys are set.

================================================================================
FIRESTORE RULES (development)
================================================================================

Allow authenticated users to add to mail collection:

  match /mail/{docId} {
    allow create: if request.auth != null;
    allow read, update, delete: if false;
  }
